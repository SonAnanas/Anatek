# ANATEK - SIFIRDAN KURULUM (5 adim)

1. Bu zip'e sag tikla > "Tumunu ayikla" > masaustune. "Anatek" adinda YENI bir klasor olusur. Eski klasorleri kullanma.
2. GitHub Desktop > File > Add local repository > bu yeni Anatek klasorunu sec > mavi "create a repository" yazisina tikla > Create repository.
3. Sol altta Summary kutusuna "ilk" yaz > "Commit to main".
4. Ustte "Publish repository" > adi: anatek > "Keep this code private" kutusundaki TIKI KALDIR (herkese acik olsun) > Publish repository.
5. GitHub'da depoyu ac > Settings > Pages > Source: "GitHub Actions" sec.
   Sonra Actions sekmesinde "Yayinla" calismasini bekle (10-15 dk). Bitince indirme sayfasi adresi:
   https://KULLANICI-ADIN.github.io/anatek/
   Bu adresi arkadasina WhatsApp'tan gonder.

Calisma 30 dakikadan uzun surerse kendiliginden hata verip durur. Hata olursa kirmizi adima tikla, son 30 satiri bana yapistir.
